# **App Name**: FundScan

## Core Features:

- Campaign Description Tool: AI-powered tool to generate engaging and effective fundraising campaign descriptions based on basic input.
- Home Screen: Display a list of fundraising campaigns with essential details: image, title, description, progress bar and 'Donate' button.
- Campaign Details Screen: Display full campaign details, including fundraiser name, target amount, raised amount, and QR code for donations.
- Create Campaign Screen: Enable users to create new campaigns with image, description, and donation goal.
- Donation via QR Code: Generate unique QR codes for each campaign, linking to a payment ID for easy donations via UPI or wallet apps.
- Progress Bar: Show a visual representation of the funds raised compared to the target amount.
- Simple Authentication: Allow users to sign up and log in using email and password.

## Style Guidelines:

- Primary color: Vibrant coral (#FF7F50) to evoke a sense of urgency and generosity.
- Background color: Light peach (#F9E7D9) for a warm and inviting feel.
- Accent color: Soft lavender (#E6E6FA) for highlighting key elements without overwhelming the user.
- Body and headline font: 'PT Sans' (sans-serif) for a modern yet approachable design.
- Use clean, minimalistic icons to represent different fundraising categories.
- Campaign cards with rounded corners and subtle shadows for a modern look.
- Smooth transitions and progress bar updates to enhance user engagement.
