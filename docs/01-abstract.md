
# Abstract

Crowdfunding has emerged as a powerful mechanism for raising funds for a wide range of causes, from personal emergencies to large-scale social projects. However, traditional platforms often face challenges related to security, transparency, and user engagement. This project, titled "Donify," presents a secure and efficient AI-powered crowdfunding platform designed to address these challenges.

The platform is built using a modern web stack, featuring Next.js for the frontend and backend, providing a fast, server-rendered React application. For the user interface, ShadCN UI components and Tailwind CSS are used to create a visually appealing and responsive design.

A key feature of this project is the integration of Artificial Intelligence using Genkit. An AI-powered assistant helps users generate compelling and persuasive descriptions for their fundraising campaigns, enhancing their potential to attract donors. This addresses a common pain point for campaigners who may struggle with copywriting. Furthermore, the system is designed to incorporate a machine learning model for fraud detection, aiming to increase the security and trustworthiness of the platform.

The platform allows users to create, manage, and donate to campaigns. User-created campaigns are stored locally using browser storage, while a set of static campaigns provides a rich content base. The user interface is designed for ease of use, featuring QR code-based donations via UPI, which simplifies the payment process, particularly for mobile users in the Indian market.

This report details the complete lifecycle of the project, from the initial problem statement and literature survey to the system architecture, implementation details, and results. It covers the frontend design, the AI flow implementation with Genkit, and the overall system functionality. The project successfully demonstrates the feasibility of using modern web technologies and AI to create a more secure, user-friendly, and effective crowdfunding platform.
